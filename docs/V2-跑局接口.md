# V2 跑局接口（run.gd 对 UI / 渲染 / 下一波暴露的字段与方法）

> 面向：`src/ui/*`、`src/render/*`、以及第 3 波接线。
> 所有字段都是 `src/run.gd`（Node2D）上的公开成员，渲染/UI 只读消费，不要写。
> 数据来源：`step()` 每帧更新；无头 `--sim` 下同样更新，可在 sim 报告里验证。

## 1. 基础状态（老字段，UI 已用）

| 字段 | 类型 | 说明 |
|------|------|------|
| `player` | Vector2 | 玩家位置（世界坐标，原点在地图中心） |
| `player_pos()` | func → Vector2 | 同上，给渲染取位置 |
| `player_hp` / `player_max_hp` | float | 当前/最大生命；`_sync_max_hp()` 保证上限变化时当前血同步 |
| `aim_dir` | Vector2 | 瞄准方向（零向量 = 自动/无瞄准） |
| `elapsed` | float | 本局已过秒数（驱动时间轴 UI） |
| `run_duration` | float | 本局目标时长；无尽模式抬到 1800 |
| `stage` | Dictionary | stages.json 当前章（含 `mechanic_id` / `boss` / `ground` / `duration`） |
| `state` | GameState | 武器/被动/军装/圣物/属性总表 |
| `enemies` | EnemySim | SoA 敌人，渲染现有逻辑不变 |
| `gems` | Array | 经验宝石 `{x, y, val}`；`val` 决定颜色（见 §4） |
| `altars` | Array | 祭坛 `{x, y, used}` |
| `active_fx` | Array | 已有特效数组（nova / arc / spark / pop，奖励/机关也往里追加） |
| `boss_index` | int | 当前 BOSS 在 EnemySim 的下标；-1 = 无 BOSS |
| `modal` / `over` / `won` | bool | 选择面板打开 / 本局结束 / 是否胜利 |
| `toast_text` / `toast_t` | String / float | 顶部提示（机关、宝箱、成就都会写） |
| `shake` / `hurt_flash` / `perfect_flash` / `level_flash` | float | 摄像机与屏幕反馈 |
| `seal` | int | 当前灾变阶数 1–21 |
| `reward` | int | 结算银两（`_finish` 里算好） |

## 2. 本波新增字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `stat_patch` | RunStatPatch | 属性补丁层；渲染一般不看，UI 调试可读 `total(key)` |
| `mechanics` | RunMechanics | 24 章机关（§3） |
| `rewards` | RunRewards | 宝石/宝箱/陶罐/祭圈/约柜（§4） |
| `covenants` | RunCovenants | 约卡（§5） |
| `achievements` | RunAchievements | 结算成就（§6） |
| `vision_radius` | float | 视野半径；>0 时渲染应裁一圈黑幕（三日之暗 140 / 基甸 110） |
| `light_t` | float | 火把全屏照亮剩余秒数；>0 时把 `vision_radius` 视为 190 |
| `magnet_t` | float | 磁力奇物剩余秒数（拾取半径 ×14） |
| `freeze_t` | float | 全场冻结剩余秒数（约·日头停留） |
| `mech_shield` | bool | 七灯台免死盾（UI 可画一个护盾点） |
| `damage_taken_total` | float | 本局累计承伤（`no_damage` 成就用） |
| `elite_kills_total` | int | 本局精英击杀数（`elite_kills` 成就用） |
| `armor_gained` | int | 本局获得军装件数 |
| `watch_count` | int | 完美闪避次数（`perfect_dodge_5`） |
| `dashes_used` | int | 本局闪避次数（`no_dodge` 判定） |
| `ach_flags` | Dictionary | 章节内临时成就标记（`no_dodge`、`armor_treasure_3` 等） |
| `bonus_silver` | int | 本局额外银两（保留字段） |
| `meta_silver_bonus` | int | 结算时入账局外的银两（钱袋奇物 +50） |
| `codex_unlocked` | bool | R01 图鉴：结算页显示「已解锁图鉴」 |
| `fast_forward_available` | bool | R04 快进：结算页可加速（本波只做标记） |
| `endless_allowed` / `endless_continued` | bool | R08/R10 无尽：是否允许 / 是否已进入无尽 |
| `reroll_plus` | bool | R09/R12 重掷 +2 已生效 |
| `chest_double` | bool | R12 宝箱银两 ×2 |
| `boss_ai` | RefCounted | 当前 BOSS AI 实例（可能为 null） |

## 3. RunMechanics（`run.mechanics`）

```gdscript
func setup(run: Node) -> void
func tick(delta: float) -> void
func on_kill(pos: Vector2) -> void
func on_level_up() -> void
func on_boss_spawn() -> void
func xp_mult_at(pos: Vector2) -> float          # 烈火窑内圈 ×2
func enemy_bullet_mod() -> Dictionary           # {active, angle, friendly}（巴别）
func elite_chest_tier() -> String               # "gold"（陨星章）
func draw_data() -> Array
func hint() -> String
```

**draw_data() 元素**（世界坐标，渲染按 `kind` 分发）：

| kind | 字段 | 画法建议 |
|------|------|----------|
| `band` | x,y,w,h,color,alpha | 半透明横带（干涸溪床） |
| `circle` | x,y,r,color,alpha,label | 半透明圆：木台/苦水/古坛/灯台/井口/麦田/树荫/篝火/树/血河/圣所/倒水坛/城墙/岩壁 |
| `prop` | x,y,r,color,label | 小物件：石柱/火把/铜蛇/牢门/石饼/石子/灯笼 |
| `hazard` | x,y,r,color,progress | 延迟伤害圈：progress 0→1 落雷/火雹/陨星 |
| `pickup` | x,y,r,color,label | 火舌等可拾取物 |
| `wall` | x,y,h,color,alpha | 红海水墙（竖线，长 h） |
| `vision` | r | 视野半径（天暗时画黑幕） |
| `overlay` | color,alpha | 全屏滤镜（玻璃海） |

**hint()**：一行中文提示（如 `干涸溪床 · 站上降温 CD -10% ｜ 石 3/5`），HUD 直接画在底部即可。

## 4. RunRewards（`run.rewards`）

```gdscript
func setup(run) / tick(delta)
func add_gem(x: float, y: float, val: int) -> void   # 自动分档、超 120 颗自动合体
func spawn_chest(tier: String, x: float, y: float) -> void  # "bronze"/"silver"/"gold"
func on_elite_killed(x: float, y: float) -> void
func draw_data() -> Array
var silver_run: int          # 本局宝箱/奇物产出的银两
var meta_silver_bonus: int   # 结算入局外的银两
```

**draw_data() 元素**：`circle`（祷告祭圈，带 `progress` 0→1 站圈进度）、`chest`（`tier` + `color`）、`pot`（陶罐）、`pickup`（奇物，`label` = 奇物 id）、`ark`（约柜）。

**宝石颜色**（渲染可直接用；`gems[i]["val"]`）：≥100 `#BFD4FF`、≥25 `#F07A9A`、≥4 `#F0D890`、否则 `#7FE0C0`。
也可直接调用静态 `RunRewards.gem_tier(val) -> Dictionary`（含 `tier/color/name`）。

## 5. RunCovenants（`run.covenants`）

```gdscript
func tick(delta) -> void
func pick(index: int) -> void      # 由 run._on_picked 在 mode=="covenant" 时调用
func draw_data() -> Array          # 已抽到的约卡 {id,name,rarity,color,text}
func title() -> String             # "约 1/2"
var cards: Array[String]           # 已持有的约 id
var enabled: bool
```

抽卡时 `run.chooser_mode == "covenant"`、`run.modal == true`，选项元素带 `kind:"covenant"`、`id`、`rarity`、`color`、`tag`（稀有度中文）、`desc`。
现有 Chooser 已能展示，UI 只需保证 `mode` 标题与三选一布局；`_sim_choose` 在 sim 下自动选第一张。

## 6. RunAchievements（`run.achievements`）

```gdscript
func evaluate(victory: bool, commit: bool) -> Array   # [{id,name,desc}]
func lines(limit: int = 6) -> Array                   # 结算页文案
var newly: Array                                      # 最近一次 evaluate 的结果
```

结算页建议：先画 `achievements.lines()`，再画 `codex_unlocked` / `fast_forward_available` / `rewards.silver_run`。

## 7. 给机关/其他系统用的 run 入口

```gdscript
func heal_player(amount: float) -> void   # 不超过上限；会触发「活水之约」满血冲击波
func hurt_player(amount: float) -> void   # 走统一减伤 + 无敌帧 + 约反伤；god 模式直接忽略
```

## 8. 选择面板（Chooser）模式约定

| `chooser_mode` | 打开时机 | 选完后 |
|-----------------|----------|--------|
| `"level"` | 升级（`_open_levelup`） | `_apply_level_choice`，可 R 重掷（`rerolls`） |
| `"altar"` | 火炭开祭坛（`_open_altar`） | `_apply_altar_choice`（祝圣/合鸣） |
| `"covenant"` | 0:00 / 6:00 抽约（R05） | `covenants.pick`，无重掷 |

## 9. 接线示例（渲染）

```gdscript
# 世界层：机关地形 + 奖励交互物
for d in run.mechanics.draw_data():
    match String(d["kind"]):
        "band":   _draw_band(d)
        "circle": _draw_ground_circle(d)
        "prop":   _draw_prop(d)
        "hazard": _draw_hazard_warning(d)   # d["progress"] 0→1
        "wall":   _draw_wall(d)
for d in run.rewards.draw_data():
    _draw_reward(d)                          # chest / pot / pickup / ark / circle
if run.vision_radius > 0.0:
    _draw_vision(run.vision_radius if run.light_t <= 0.0 else 190.0)
```

> 注意：world_renderer.gd 当前只画老字段（`gems` 用 `val` 分色、`active_fx` 只认 nova/arc/spark/pop）。
> 新 draw_data 不会被自动渲染，需要 UI 代理按上表接入。
