## 2. 本轮读图与模拟查出的真实问题（已修）

| 问题 | 表现 | 根因 | 修法 |
|---|---|---|---|
| 升级池抽空后领受白丢 | 40 次升级里有 8 次三选一全是"已满级"，选完什么都没发生 | `_level_options()` 在武器/宝物池抽空时直接返回空数组 | 新增**常备祝福**六条（刚强的灵 / 敏捷的手 / 快如母鹿 / 生命的泉源 / 宽阔之地 / 明光照眼），池空时兜底，每条最多 30 次；`game_state.blessings` + `add_blessing()`，`run.gd` 的 `BLESSING_DEFS`/`_blessing_options()` |
| 首领阶段行糊成 JSON | 屏幕上出现 `阶段 1 · {"id":"ring_burst","cd":2.5,"params":{...}}` | `_phase_skills()` 对 dict 直接调 `String()` | `SKILL_LABELS` 映射成"环火爆 / 瞄准齐射 / 召唤从者 / 冲锋 / 封锁地带 / 自愈 / 立起图腾 / 新星爆发"，去重后「、」连接，并 `_fit(...,300.0,9)` 防越界 |
| 地面出现英文标签 | 画面里一个树形光晕旁写着 `tree` | `mechanics.draw_data()` 直接把 `kind` 当 label | 新增 `SPOT_NAMES`（21 条中文短名）+ `_spot_label()`；拾取物不再带字 |
| 结算页两行自相矛盾 | "舍客勒合计 1776" 旁边"本局拾取 +0" | `_picked_shillings()` 只算地面银钱，`_picked_total()` 才含局内结算银两 | 暂停页与结算页两处都改用 `_picked_total()` |
| 相机抖与全屏泛光无视特效档 | 把特效关到 0，受击仍抖屏、升级仍泛光 | `run.gd` 的 `cam.offset` 抖动与 `hud.gd` 的 `hurt_flash`/`level_flash` 没读档位 | 都加 `UserSettings.fx_at_least(1)` 门（低血脉冲描边保留） |
| 序章与章节字幕没人读 | `data/intro.json` 写了 24 章开场，代码里零引用 | 叙事代理只交数据，没接线 | 标题页画序章首句；进局后 `_setup_intro()` 逐行淡入（sim 模式跳过，不污染确定性） |
| 默认角色兜底串写死 `david` | 没有存档时标题页与营地显示的是大卫而不是亚当 | 五处硬编码 | `title_screen.gd:96,203`、`camp_screen.gd:208,283,286` 全改 `adam` |

## 5. 已知限制（没做的）

1. **敌方图集仍是程序化占位级**：士兵在 2× 下读作"土色方块 + 一根长矛"，精英与 BOSS 更明显。这是 V4 契约里排在第 2 优先级的真实美术缺口，等外部素材或重画，不在本轮范围。
2. **后期章节在默认解锁下会输**：`elah_valley`（第 13 章）默认存档 3 武器 / 4 宝物，牧杖 + 火把合成"云柱与火柱"后基础武器只剩 1 把，`t=421.4` 战败（`level=20`）；这是解锁曲线按设计预期，不是数值缺陷（同关 seed 1–4 全胜）。
3. **`docs/数值-VS对齐.md` 的结论数字与当前 build 不一致**：那份文档的 841.8s / L44 / 10225 击杀是它自己那一轮刷怪预算下的测量；后来 `data/stages.json` 的刷怪预算被收敛过，当前定稿以本文 §3 的 706.8s / L31 / 3193 为准。
4. 标题页底部 y≈332–357 还有一条约 25px 空带（序章句只有一行）。
5. 暂停页属性右列数字贴住内框右沿（未溢出，但两侧留白不对称）。
6. 特效三档只影响视觉，不改变模拟；`--sim` 全程走 0 档（headless 无渲染）。
