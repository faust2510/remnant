# V4 美术重制契约（像素图集）

> 用户判定：V3 的图集「丑爆了」，而且「不像圣经里的人物，没有对应特征」。本轮唯一标准是
> **一眼认得出这是谁**：轮廓 + 标志性道具 + 专属配色，三者缺一不可。

## 1. 几何与产出契约

| 图集 | 单格 | 帧数 | 行数 | 尺寸 | 脚底 y | 产出方 |
|---|---|---|---|---|---|---|
| assets/sprites/witnesses.png | 48x48 | 8（0-3 站立呼吸，4-7 走路） | 20 | 384x960 | 44 | 三个角色 agent，主控合成 |
| assets/sprites/enemies.png | 32x32 | 6 | 8 | 192x256 | 28 | enemy agent |
| assets/sprites/projectiles.png | 16x16 | 8 | 8（stone/arrow/flame/blade/note/water/shock/spark） | 128x128 | - | icons agent |
| assets/sprites/props.png | 16x16 | 8 列（gem0-3, coin, coal, 空, 空） | 1 | 128x16 | - | icons agent |
| assets/icons/weapons.png | 32x32 | - | 5 列 x 4 行（20 把，顺序 = data/weapons.json） | 160x128 | - | icons agent |
| assets/icons/passives.png | 32x32 | - | 5 列 x 4 行（20 件，顺序 = data/passives.json） | 160x128 | - | icons agent |

- **一律朝右绘制**；运行期按单格镜像得到朝左（整图翻转会让帧序倒放，代码已按格镜像）。
- 全整数坐标、硬边、禁止抗锯齿；描边统一 1px #0A0E14（artbase.outline）。
- 每格必须非空、不得被裁切（artbase.validate）。
- 角色 agent 只写 tools/out/wit_<id>.png（48x384，8 帧横排）与自己的 tools/art/chars_[abc].py，
  **不要**直接写 assets/sprites/witnesses.png（主控合成，避免互相覆盖）。

## 2. 画风规则（不是建议，是必须）

1. **3-4 阶明暗**：每块布料/金属至少要有 base / dark(x0.74) / light(x1.18) 三档；大面积纯色块 = 不合格。
2. **剪影优先**：缩到 48px 后先看剪影；头饰、披风、手持道具必须突出轮廓，不能全贴在身体内侧。
3. **一角色一配色**：主色 + 强调色（金/银/火）固定，禁止所有人同一套灰棕。
4. **道具要「举起来」**：手持物画在身体外侧轮廓外 2-6px，不要和躯干重叠糊成一团。
5. **金属**：竖条高光 + 暗边；**布料**：衣褶用 1px 深色斜线。
6. **面部**：眼睛 1px 深色，不要画大眼白；老人加 1px 皱纹/胡须分层。
7. 站立帧（0-3）只做呼吸起伏（+-1px）与轻微摆动；走路帧（4-7）腿要有 2px 前后错位、手臂反向摆。

## 5. 弹道与图标（icons agent）

- projectiles.png 8 行 x 8 帧：stone（石弹）/ arrow（箭）/ flame（火）/ blade（刃）/ note（音波）/ water（水）/ shock（震荡环）/ spark（火星）。每行 8 帧做 2-3 帧闪烁或旋转，其余帧可复制。
- 16px 内的可读性：本体占 8-12px，带 1px 描边与高光；石弹要圆润有体积，刃要薄而亮，音波是同心弧。
- props.png：宝石 4 档（蓝→紫→金→橙红，切割面 3 条高光）、银币（舍客勒）、火炭（暗红裂纹）。
- 武器图标 20 个：按 data/weapons.json 顺序，**图标必须画出武器本体**（投石索=绳+兜，牧杖=弯头杖，火把=柄+焰…），不要抽象符号。
- 被动图标：果实类用果子+光晕；军装类用装备本体（腰带/胸甲/鞋/盾/盔/剑）；宝物类用器物（乳香炉/没药瓶/油瓶/细麻布/以弗得胸牌）。

## 6. 验收

1. python3 tools/gen_art.py 能一把重跑，产出所有图集并通过 tools/artbase.validate。
2. 每个 agent 自己用 read_image 看 4x 放大预览图，**至少迭代两轮**，直到：缩到 1x 能认出是谁、道具在轮廓上可辨、没有糊成一块。
3. Godot 门禁：--headless --path . --import 与 --headless -- --sim --sim-speed=900 --no-meta 均 exit=0 且 SCRIPT ERROR 0。
4. 不 git commit（主控统一提交）。
