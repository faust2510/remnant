# P4 · 第二张试炼：犹大旷野

以拉谷之外的第二张地图，验证「一张地图 = 一组合法组合 + 一条地图修饰」这套结构可复用。

## 玩家可见的变化

- 营地新增「试炼」行：← → 在已解锁地图之间切换，`出发 → <地图名>` 直接进对应地图。
- 犹大旷野需先通关一次以拉谷才解锁（数据字段 `unlock_wins`）。
- 地图修饰：敌人移动速度 ×1.12、舍客勒收益 ×1.25；地图主题是「正午灼热的石灰岩荒原」。
- 地面配色与装饰来自 `data/stages.json` 的 `ground`，不再写死在渲染器里：`base / speckle / zone` 三色 + 可选 `rocks`（确定性散布的石灰岩碎块，不占随机数、不会逐帧闪烁）。

## 代码改动

- `src/run.gd`：`STAGE_ID` 常量 → `stage_id` 变量（来自 `RunCfg.stage_id` 或 `--stage=`，找不到就回落到以拉谷）；新增 `stage_speed` / `stage_coin`；`_spawn_at_ring()` 里对新生敌人乘速度；`_finish()` 里舍客勒乘 `stage_coin`；`--shot-fast` 未配 `--shot-at` 时自动把目标时间设为快进终点。
- `src/core/meta.gd`：新增 `stage_id` 并进存档（`version` 仍是 1，旧档缺字段时默认以拉谷）。
- `src/camp_screen.gd`：行数 7 → 8（6 强化 + 试炼 + 出发），行高 30 → 27；`_stage_row()` / `_cycle_stage()` / `_stage_unlocked()`；←→ 在试炼行切换地图，其他行仍是调七印。
- `src/render/world_renderer.gd`：地面三色与碎块改读 `stage.ground`；区域（香炉等）描边从 0.5 降到 0.26 并加内圈，避免大半径区域糊成一片。
- `src/core/run_cfg.gd`：已有 `stage_id`，营地出发时写入。
- 地图修饰新增 `cooldown`（以拉谷 0.9）：`src/core/game_state.gd` 加 `var stage_cd: float = 1.0`，在 `recompute()` 里性能被动之后乘进 `cooldown_mult`（放这里是为了升级重算不会把地图修饰冲掉）；`src/run.gd` 解析 `stage_cd = float(mods.get("cooldown", 1.0))` 后 `state.stage_cd = stage_cd; state.recompute()`。
- 模拟报告行末尾加 `cd=%.2f`（读 `state.stats["cooldown_mult"]`）方便核对地图修饰是否生效。

## 调平衡（同轮内完成）

初版数据（per_minute 78、毒蝎伤害 4）在 4 印下三连跑只有 1/3 通关（495.9s / 698.5s 两次阵亡，673.1s 一次仅剩 18 HP），比以拉谷明显更不稳定。原因是旷野敌人整体速度 ×1.12 + 毒蝎 charger 高频贴身，同一套自动驾驶的站位容错被压缩。

调整：`budget.per_minute` 78 → 66、`max_alive` 640 → 560、`scorpion.damage` 4 → 3（不动血量与速度，保留「快而脆」的地图性格）。

复测（大卫自动驾驶，`--sim --sim-speed=900 --no-meta`）：

| 印 | 结果 | 用时 | 等级 / 击杀 | 剩余生命 |
|---|---|---|---|---|
| 4 | 通关 | 750.0s | 45 / 7316 | 64 / 140 |
| 4 | 通关 | 750.0s | 44 / 8816 | 140 / 140 |
| 4 | 通关 | 750.0s | 44 / 8897 | 112 / 140 |
| 7 | 通关 | 750.0s | 46 / 9725 | 200 / 200 |

4 印三连全通、7 印单跑通过；比以拉谷略难（以拉谷 4 印稳定通关、7 印约 2/3 通关），符合「第二张图是升级版试炼」的定位。
