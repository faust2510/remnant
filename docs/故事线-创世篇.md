> 定位：叙事文档，不参与运行，不被 `src/` 读取。
> 权威：`docs/设计圣典-v2.0.md`（数值与四条红线）＋ `docs/设计大纲-v0.1.md` §3（世界观与叙事框架）。

## 0. 一句话

故事不再从「一个无名守望者」开始，而是从伊甸东门外的那一夜开始：门里有园子，门外有荆棘；两个被赶出去的人先站进了异象，二十四章正典才从他们身后一路铺到玻璃海。

## 1. 序章：创 1–3（伊甸与堕落）

### 1.1 四拍年表（叙事用，不是解经）

| 拍 | 经文 | 场上发生的事 | 叙事功能 |
|---|---|---|---|
| 一 · 好 | 创 1:1–2:3 | 光与海分开，地长出草木，人被造，一切「甚好」 | 给玩家一个**可以失去的东西**。没有「好」，堕落只是背景板 |
| 二 · 托付 | 创 2:4–25 | 人被安置在园中，「修理，看守」；女人从肋旁而出；「可以随意吃」 | 把「看守」这个动词交给玩家：本作自称「守望者」，词源就在这里 |
| 三 · 失守 | 创 3:1–7 | 蛇问「神岂是真说」；女人看那果子「好作食物」；男人在场、沉默；眼睛明亮，知自己赤身 | 失败不是被设计的桥段，是一次「看守的人没有看守」 |
| 四 · 门外 | 创 3:8–24 | 审判、皮子作衣服、被赶出去；东门设基路伯与「四面转动发火焰的剑」 | 序章的落点是**门口**：第 1 章 `ch01_eden` 的 BOSS 就是这把剑的幻象 |

叙述只写「人这一侧」：园中的风、树叶的声音、门外的荆棘、剑转过一圈时地面的热度。神迹只作为背景恩赐与机制演出出现（圣典 §1.3 红线一），不写神的脸，不写神的第一人称台词。

### 1.2 序章交代三件事（每件一句，其余留给玩家补）

1. **人是被造的，不是自己成的** —— 所以本作没有「天生英雄」，只有被唤醒的见证人。
2. **园子是失去的，不是打赢的** —— 所以全程没有「夺回伊甸」的任务，只有「在门外站住」。
3. **门是被守着的，剑是自己转的** —— 所以第一章的第一形态敌人是异象（基路伯幻象），不是血肉。

### 1.3 与第 1 章机制的接缝

`ch01_eden` 的 `eden_fall` 机制（圣典 §2 第 01 行）：300s 刷出分别善恶树与禁果，吃下得 +40% 伤害，但地面切成荆棘荒原（经验 -15%、12 条减速带）；坚持到 360s 不吃，树枯萎、保留 -10% 冷却。

叙事上这是「门口还留着一棵树」：不是引诱玩家再犯一次错，而是把那句「可以随意吃」与「不可吃」摆在同一块地上，让玩家自己选。代价由玩法和数值说话，旁白不点评。

## 2. 亚当与夏娃：为什么可以作首两位见证人

### 2.1 规则依据（两条既有设定，不是新发明）

- `docs/设计大纲-v0.1.md` §3：「历代圣徒以异象形式与你同站。这是'不同时代角色同场'的叙事许可。」
- 圣典 §1.3 红线一「不扮演耶稣、不描绘父神形象」：可见证人的边界是「受造的人」。亚当、夏娃是受造的人，站在最前不越过红线。

由此得到本作的演出规则：**玩家不是「变成」亚当，而是「异象里他的身影与你同站」**。这一条同时解释了两件事：为什么同一个见证人可以重复出场；为什么他开口都是回忆的语气，而不是此刻对你说的话。

### 2.2 与来 12:1 的框架不冲突

标题页已经原样引用来 12:1「我们既有这许多的见证人，如同云彩围着我们」（未改写）。把亚当、夏娃放在名单最前，需要正面回答一个问题：希伯来书 11 章的信心名单从亚伯开始，为什么不从亚当开始？

- 11 章排的是「应许—信心」的链条（亚伯、以诺、挪亚、亚伯拉罕……）。亚当、夏娃在这条链的前情里：领受应许（创 3:15）、被赶出去、却仍然生养。名单没写他们，不等于他们不在云彩里，只是作者选了亚伯作起点。
- 来 12:1 的「见证人」（μάρτυς）强调**旁观与见证的席位**，不是排名。玩家需要的第一批旁观者，恰恰是最先看见乐园失去的人——他们的见证内容只有一句：「门确实存在过，也确实关上了。」
- 本作不改经卷次序，也不声称「亚当夏娃是信心英雄」。我们只补上「起点」这一格，并且把他们放在**最基础**的位置而不是最荣耀的位置。这在游戏里是一次诚实的弱化：他们没有神迹、没有军功，只有「修理看守」与「生养」两个动词。

### 2.3 数值解释（为什么他们「最基础」）

| | 亚当 `adam` | 夏娃 `eve` | 对照（现有角色） |
|---|---|---|---|
| 生命 / 移速 | 150 / 70 | 136 / 74 | 大卫 140 / 72；挪亚 165 / 66 |
| 起始武器 | `staff` 牧杖（近战扇击，自动朝最近目标，自带击退 90） | `torch` 火把（环绕自动命中，无需瞄准） | 都是「默认解锁」三把之一 |
| 特质 `perk` | 最大生命 +10、受到伤害 -10% | 拾取范围 +30%、升级回血 +10% | 纯数值，全部有引擎实现 |
| 三印觉醒 | 尘土与生气：最大生命 +25、受击推开身边敌人 | 众生之母：升级回血 +15%、拾取范围再 +20% | 同样只用已接线的键 |

两条「低操作门槛」的共同点：不依赖手动锁头（大卫的 `aim_crit_mult` 才需要）、不依赖闪避时机、不依赖爆发窗口。新手先学会「站住」，再学瞄准——这和第 1 章「不吃果子」的设计意图是同一件事。

### 2.4 写作公约（决定文案为什么克制）

1. **不布道**：不写「你要相信」「神爱你」「愿你平安」这类劝勉句。宗教语气全部降级为陈述：动作、物件、光、风。
2. **不忏悔剧**：不写哭诉、互相指责、长篇悔改独白。堕落已经被叙述过了（创 3），游戏不重演审判。
3. **不越位**：不写神的第一人称，不写耶稣，不写「你替他们赎罪」。玩家的位置是**同站**，不是救主。

## 3. 第 1 章开场白（可直接粘贴）

### 3.1 静帧三句（推荐：逐行淡入，每行约 2.2s）

```
异象先把你带到一道门前：门里是园子，门外是荆棘。
基路伯的剑转了一圈，火没有落下——它在等一个还肯站着的人。
亚当与夏娃曾在这里被赶出去；今夜，他们的身影与你同站。
```

节奏：第 1 句给地点（东门），第 2 句给压力（剑在等），第 3 句给位置（不是扮演，是同站）。三句都没有「神」字，没有命令句，也没有解释教义。

### 3.2 短变体（同一接口，按状态切换）

- **重玩**（已通关过本章）：`东门的火还在转。` / `你回来得比上次早。`
- **失败重来**（上一局死在本章）：`门没有关，剑也没有停。` / `云彩还在看着。`
- **首进且已选中亚当或夏娃**：在 3.1 之后追加 `名字被记下来的人，先学会了站在门口。`

（严格说只有 3.1 是「章节开场白」，3.2 是同一落点的短变体。）

### 3.3 序章提示（可选：标题页之下，或章节选择页之上，两行）

```
园子在东边，门已经被守着；守门的剑四面转动，谁也进不去。
可门口还留着一棵树——像是有人还愿意再等一等。
```

### 3.4 接线状态（重要，别误以为已在游戏里）

- 文案数据已写入 `data/intro.json`：`prologue.lines`、`chapter_intro.ch01_eden.lines`、`chapter_intro.ch01_eden.variants`。
- **当前没有任何 `src/` 代码读取 `data/intro.json`**。叙事代理的写权限不含 `src/`，接线由主控或 UI 代理完成；在那之前，本节文字只作文档与数据源。
- 建议接法（给 UI 代理，二选一）：① `src/core/game_data.gd` 增加 `intro` 字段并在 `reload()` 里 `_load_optional("intro.json")`；② 章节开场处直接读文件。两种都不需要改本文件。
