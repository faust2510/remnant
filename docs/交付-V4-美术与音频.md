# 交付 · V4 美术重制与音频

> 版本：V4 ｜ 日期：2026-11-17 ｜ 项目：余民 The Remnant ｜ 引擎：Godot 4.7.1（GDScript）

## 1. 本轮要做什么

用户在本轮提了两组要求（m03178 / m03180）：

1. **美术与弹道全面重做，人物要有圣经特征** —— 现有图集是 V3 的程序化占位（32px、4 帧、细到看不清的道具），要重画成 48px 的、能靠道具一眼认出是谁的行走图；敌人同理；弹道不能再是「圆点串珠」。
2. **武器/被动逐步解锁** —— 开局不能把 20 把兵器、20 个宝物全塞给玩家，要有解锁条件与营地提示。
3. **每章地表机制与音效音乐「全都做掉」** —— 每章要有自己的地面机制，另加音效与背景音乐。

其中第 3 条的**每章地表机制**在 V2 已经落地（`data/stages.json` 的 24 章各带一个 `mechanic_id`，`src/systems/mechanics.gd` 里有 24 个对应实现，如 `dry_creek` / `sea_walls` / `glass_sea`），本轮**没有改机制逻辑**，只补了音效与音乐。本文件覆盖的是本轮实际改动：图集、渲染、音频、解锁、以及随之而来的 UI 取整改动。

## 3. 图集与几何

`assets/sprites/atlas.json` 记录六张图的几何，`src/render/sprite_bank.gd` 在启动时先铺内置 `DEFAULT_SHEETS`（V3 的 32px/4 帧），再被 `atlas.json` 逐字段覆盖；所有渲染代码只问 `cell_of() / frames_of() / feet_of() / frame_rect() / witness_row() / enemy_row()`，因此**格宽从 32 改 48、帧数从 4 改 6/8 不需要动任何渲染代码**。

| 图集 | 行 | 格 | 帧 | 脚底 y | 备注 |
|---|---|---|---|---|---|
| witnesses | 20（david…john_patmos，顺序同 `data/characters.json`） | 48 | 8 | 44 | 朝右绘制，镜像由 `_make_flip` 逐格生成 |
| enemies | 8（soldier/archer/raven/beast/scorpion/six_finger_giant/goliath/the_tempter） | 32 | 6 | 28 | 其余 28 个敌人 id 走 `enemies.aliases` 映射 |
| props | 1 | 16 | — | — | 宝石 4 档 → 银币 → 火炭 |
| projectiles | 8 | 16 | 8 | — | stone/arrow/water/blade/thorn/hammer/curse/spark |

**镜像的坑**：`_make_flip` 必须按 `cell_of()` 逐格镜像；整张图 `flip_x` 会把 8 帧顺序倒放，走路会「倒着迈腿」。

**回退**：图集缺失、行号越界、`SpriteBank` 全空时一律走 `_draw_player_proc` / `_draw_enemy_proc` / `_draw_shot_proc`，不 push_error、不崩；`--headless` 下的 `--sim` 完全不依赖纹理加载。

**画风红线**（完整版见 `docs/V4-美术重制契约.md`）：1px 深色描边、单侧主光、饱和色只给身份道具、禁渐变禁抗锯齿、暗底上角色必须比背景亮 2 个色阶。`artbase.outline()` 只做**一次** 3×3 膨胀（早期版本连做三次，每格变成 6px 黑框，角色读作「站在黑墓碑里」）。

## 4. 音频

- 12 个音效由 `tools/gen_sfx.py` 合成（无第三方素材）：`slash / hit_light / hit_heavy / enemy_death / pickup_gem / pickup_coin / level_up / fuse / boss / hurt / defeat / ui`。
- 统一峰值 −3dBFS、44.1kHz 单声道，避免同屏几十次击中时叠加削波。
- `src/core/sfx.gd` 重写：保留原有 `play(name)` 与 `enabled` 语义，内部维护 **103 个语义别名**（旧名 `hit` / `level` / `pickup` / `dash` 仍可解析，调用点零改动）；运行时创建 `SFX`（−2dB）/ `Music`（−8dB）两条总线并入 Master；`headless` 自动静音降级。
- 营地音乐 `assets/music/camp_loop.ogg` 64.000s，循环接缝做过连续性校验。
- **接入注意**：`assets/music/` 是新目录，首次必须跑一次 `--headless --import`，否则 `play_music` 静默不播。

## 5. 渲染与弹道

- 新增 `src/render/projectile_visuals.gd`（207 行）：20 把武器 → `{row, tint, scale, trail, gap, size, st}` 的映射表，`resolve(color, status, size, friendly)` 按弹幕颜色/体型反查贴图行，不加载纹理。
- `world_renderer.gd`：
  - 玩家/敌人统一 `draw_texture_rect_region` + `roundf` 整像素落点；体型 `r >= 9` 的精英/BOSS 用 2 倍图，其余 1 倍（只允许整数倍）。
  - 弹幕：暖光两层光晕 + **4 段锥形残影**（间距随速度），替掉旧的等距圆点串。
  - 新增 `_corpses`：8px 格双缓冲比较前后帧 + 3×3 邻居容差判定死亡，0.20s 内 scale 0.72→1 淡出，不打断同屏节奏。
  - 新增 `_hit_fx`：只读 `run.dmg_events` 游标，`_hash2` 生成确定性 3/5 颗火花（不消耗 rng，保证 `--sim` 可复现）。
- HUD 头像与标题立绘改为**整数倍**：48px 格 2× 进 96px 框居中留边；HUD 头像取头部 32×32 裁剪 1:1（原来把 48px 硬塞 32px 框 = 0.667× 非整数缩放，糊边）。

## 6. 解锁体系

- `data/weapons.json` / `data/passives.json`：每个条目新增 `unlock` 字段（条件类型 + 阈值 + 文案 key）。
- `src/core/meta.gd`（+176）：`is_unlocked()` / `unlock_progress()` / `grant_unlocks()`，老存档缺字段时按「已解锁」兜底（向后兼容）。
- `src/camp_screen.gd`（+281）：军装/圣物卡片显示解锁条件与进度条，未解锁灰化但仍可查看说明。
- `src/ui/ui_text.gd`（+85）：`unlock_rule_text / weapon_unlock_note / passive_unlock_note / new_unlock_text / new_unlock_lines`，统一「条件 → 进度 → 解锁奖励」三段式文案。
- 副作用（预期内）：`--sim` 默认存档只开 3 件兵器，所以门禁日志里的武器池只剩 `投石索 / 云柱与火柱` 之类。

## 8. 已知限制

1. 图集是**程序化像素画**，风格统一、可读性强，但精细度仍属占位级（道具细节靠轮廓提示，靠 1× 可辨而非近看惊艳）。
2. 8 种敌人剪影承载了 36 个敌人 id（`atlas.json` 的 `enemies.aliases`），同 id 不同章会看到同一剪影换色。
3. 三选一卡片出处条字号压到 9px 是平衡结果；再小中文就糊。
4. 音频只有一首营地循环，战斗音乐未做（用户未要求，暂留）。
5. `tools/out/` 是 25MB 预览目录，已加入 `.gitignore`，不入库。

## 9. 复现步骤

```bash
# 图集：逐角色重画 → 合成六张图集（幂等，缺件打 warnings 不崩）
python3 tools/art/chars_a.py && python3 tools/art/chars_b.py && python3 tools/art/chars_c.py
python3 tools/art/enemies.py && python3 tools/art/icons.py
python3 tools/gen_art.py

# 音频：合成 12 个音效 + 营地循环
python3 tools/gen_sfx.py

# 首次接入新目录后必须重新导入
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --import
```
