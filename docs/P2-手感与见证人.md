## 3. 标题与见证人选择

- `src/title_screen.gd`：640×360 标题页，2×2 见证人卡（名字 / 出处 / 起始武器 / 两条能力说明），

## 4. 敌人回收（节奏关键）

类幸存者里玩家通常比敌人快，追不上的敌人会永远留在屏幕外，既白吃 CPU 又让画面发空。

`run._recycle_far()`：每 0.5 秒把距离 > 700px 的普通敌人重新投放到 330~440px 外圈（BOSS 不动）。

实测（摩西，自动驾驶）：

| 时间 | 回收前同屏存活 | 回收后同屏存活 |
|---|---|---|
| 109s | 309 | 299 |
| 129s | 81 | 369 |
| 139s | 85 | 392 |

回收前被 AOE 清一波就空场；回收后稳定维持 300~400，屏幕上保持 25~40 只。
