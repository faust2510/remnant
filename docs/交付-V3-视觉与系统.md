### 1.2 渲染实现

- `src/render/sprite_bank.gd`：`SpriteBank.witness_rect/enemy_rect/weapon_icon_rect/passive_icon_rect`，图集缺失时全部返回空 Rect2。
- `src/render/world_renderer.gd`：`draw_texture_rect_region` 替代 `draw_rect`；按移动方向 `flip_h`；4 帧呼吸/跑动；
  受击白闪；`scl = 2.0 if r >= 9 else 1.0`（只允许整数倍，避免糊）；dst = `(x-16scl, feet-29scl, 32scl, 32scl)`，`feet = y + r*0.62`。
- **镜像坑**：整图 `flip_x` 会把 4 帧顺序倒放，所以 `_make_flip` 逐 32px 单元镜像。
- **回退**：`enemy_row < 0`（28 种未收录敌人）或图集缺失 → `_draw_enemy_proc` / `_draw_player_proc` 程序化兜底，不崩、不报错。
- 弹幕残影 4 段（圣石土金 / 音刃淡金 / 敌弹红光）；`arc_melee` 三层渐变扇形 + 0.22s 淡出扩张；orbit 火花；zone 上升烟雾。
- 宝石四档菱形切割 + sin 悬浮 + 高光；火炭跳动火芯；地面舍客勒银币（精英/BOSS 必掉 +15、普通 4% +2）。
- 浮动伤害数字限流 40；暴击 ×1.4 且色 `#E0B85A`；只读 `run.dmg_events` + `run.dmg_life`（run 侧是自过期并行数组，渲染侧绝不能清空，否则错位）。
- 地面多层枯草 / 碎石 / 裂纹 / 干涸河床暗纹，全部整数坐标 `_hash2` 哈希，不消耗 rng（否则破坏确定性）。
- 对外数据契约未动：`src/sim/enemy_sim.gd`、`src/sim/projectile_sim.gd` 的字段与语义原样保留，
  `--headless -- --sim` 不加载任何纹理也照常跑。

## 2. 系统完整度（Prompt 2）

- 存档 `user://save.json` `version = 1`，字段缺省即回落默认值（向后兼容老档）。
- 暂停菜单：`Esc` 或右上 `[||]`，四个按钮（继续 / 重开本局 / 返回营地 / 音效开关）+ 武器宝物与实时属性摘要。
  实现位于 `src/run.gd`（`toggle_pause / pause_move / pause_confirm`，`step()` 首行 `if paused: return`）。
- 地面银钱实体：`_spawn_coin`（精英/BOSS v=15、普通 4% v=2）→ `_pickup_coins`（用 `stats.pickup_radius`）→ HUD `picked_shillings`；
  `_finish` 里 `ground_silver = round(picked_shillings * stage_coin)` 并入 reward 且单独入账 `Meta.shillings`。
- 修复三处逻辑债：
  - `src/core/meta.gd:139` `reward_for` 显式收本局 seal（跨局难度不再串味）；
  - `src/run.gd` 接触伤害普通怪上限 10 / 精英·BOSS 放宽 18，统一 `hit_cd = 0.60`；
  - `src/sim/enemy_sim.gd` 用累计 `sim_time` 取代 `Time.get_ticks_msec()`，并把 `run.rng` 注入 EnemySim / WeaponRunner，
    4 处全局 `randf()` 换成 `fx_rng` → `--sim` 两次运行日志 diff 为空。
- 六种祝圣 modifier 真机制：tidal_push / trail_fire / wall_push / holy_smoke / echo_blade / shockwave（全部经 `_spawn_zone` 系列落地）。
- 成全（ascend）永久参数：`bake_ascend` 在 overrides 之后乘入 弹数 +2 / 半径 ×1.35 / 伤害 ×1.25 / 冷却 ×0.85 / 射程 ×1.12 / 扇形 ×1.1，写进 `entry["ascend_params"]`。

### 3.1 本轮读图后修掉的 6 处真实问题（每处都复拍验证）

1. **三选一简介压名字**：`draw_multiline_string` 的 `pos` 是**首行基线**不是左上角（逐行像素剖面实测），
   基线 +30 时首行占到 +22 与名字（基线 +24）交叠 → 改 +34。
2. **三选一简介钻到状态角标下面**：desc 宽度原先没让开右上角标 → 改用 `maxf(120, name_w)`（`name_w` 已让开角标）。
3. **底部出处条把中文压扁**：条带 10px 高塞 8px 中文，实测字形只剩 6 行像素 → `SHEET_H 44 / FOOT_TOP 50 / FOOT_H 18`，
   出处字号 10（超宽依次降 9/8），基线 +13，斜体剪切 0.20 → 0.16。
4. **结算页数字自相矛盾**：合计 3152 但括号里「局内拾取 0」→ 抽出 `_picked_total()`（地面银钱 + 即时银两，同乘关卡币值），
   合计括号、明细行、本局拾取三处同源。
5. **机制条中文糊成一团**：字号 8 → 9（`干涸溪床 · 站上降温 CD -10% ｜ 石 3/5` 现在可读）。
6. **`CD -10%` 触发每帧 `String formatting error`**：该行还带 `%d` 石数格式化，裸 `%` 被当格式符 → 写 `10%%`。

## 6. 已知瑕疵与下一步

- 图集是程序化占位级：轮廓可辨、调色统一，但细节精度有限；后续换手绘或 CC0 素材只需替换同名图集（代码只认图集行列）。
- 4 帧动画用同一姿势的呼吸/位移变体，跑动与攻击动作还没有独立帧。
- 28 种未收录敌人仍走程序化回退（可读但不统一）。
- 存档只到 version 1；还没有音频资源（音效开关目前控制的是占位 bus）。
- 下一步建议：手绘替换图集 → 攻击/受击独立帧 → 每章地图机制专属地表 → 音效与音乐。
