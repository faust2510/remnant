# V2 局内系统（src/systems/）实现说明

> 作用域：`src/run.gd`（唯一修改者）+ `src/systems/*.gd`（本波新建）。
> 只读依赖：`src/core/*`、`src/sim/*`、`src/combat/weapon_runner.gd`、`data/*.json`。
> 所有系统都不引用场景树节点 API，能在 `--headless --sim` 下独立跑完一局。

## 1. 架构

```
run.gd（唯一驱动）
 ├─ state: GameState              —— 武器/被动/军装/圣物/属性总表
 ├─ stat_patch: RunStatPatch      —— 本局属性补丁层（所有系统的 buff/debuff 都走它）
 ├─ mechanics: RunMechanics       —— 24 章机关、地形、Hazard、可交互点
 ├─ rewards: RunRewards           —— 经验宝石分级/合体、三档宝箱、陶罐奇物、祷告祭圈、约柜
 ├─ covenants: RunCovenants       —— 约卡（R05）抽取与 effects 注入
 └─ achievements: RunAchievements —— 结算成就判定（读 mechanics.flags + run.ach_flags）
```

### 1.1 RunStatPatch（src/systems/stat_patch.gd）

- 每个系统用 `add(id, key, op, val)` 打补丁（`op` = `"mul"` / `"add"`），`remove(id)` 撤销，`has(id)` 查询。
- `apply()` 每帧在 `GameState.recompute()` 之后把补丁叠到 `state.stats`；`stats_changed` 时清空已应用记录，避免重复乘算。
- 约定：**系统不得直接写 `state.stats`**，否则下一次 recompute 会覆盖，且叠加顺序不可控。
- 支持的键：`damage_mult / cooldown_mult / area_mult / proj_speed_mult / speed / crit_chance / crit_mult / max_hp / armor / lifesteal / xp_gain / silver_mult / knockback_mult / heal_per_sec / pickup_radius` 等 GameState 已有键。

### 1.2 每帧顺序（run.step，src/run.gd:332 起）

1. 计时器衰减（hit_cd / dash / toast / shake / flash）
2. 完美闪避慢动作 `watcher_t`、约·日头停留冻结 `freeze_t`
3. 七印渐入 `seal_ramp` + 敌人血量缩放
4. **mechanics.tick → rewards.tick → covenants.tick → stat_patch.apply → _sync_max_hp → heal_per_sec**
5. `_move_player` → 敌人网格重建 → `weapons.tick` → `shots.update` → `enemies.update`
6. 接触伤害（普通怪上限 10、BOSS 在场 18，乘 seal_dmg）→ 敌方弹幕
7. `_drain_fx` → `_consume_deaths`（机关 on_kill、经验、圣物/约、精英宝箱）→ `_pickup_gems`
8. `_check_ascend` → `_spawner` → `_recycle_far` → `_altars_and_events`（精英/BOSS/祭坛）
9. `_recompute_boss` → `_tick_boss_ai` → 到时结算

## 3. 约（Covenants，R05）

- 触发：`GameState.relics` 含 `R05`（或 relics.json 里 `effect == "covenant_system"`）。
- 抽卡：0:00 与 6:00 各 1 张，最多 2 张；用现有 Chooser，`mode = "covenant"`，三选一（从 16 张里不重复抽 3 张）。
- `pick(index)` 后按 `effects[{key,value}]` 注入 `RunStatPatch`：
  `damage_mult / cooldown_mult / area_mult / projectile_speed(→proj_speed_mult) / move_speed(→speed) / max_hp / xp_gain / silver_gain(→silver_mult) / knockback_mult` 走 `mul`；
  `crit_chance / crit_damage(→crit_mult) / armor / lifesteal` 走 `add`。
- 有独立语义的 8 张写进 `GameState` meta，由 run 消费：
  `cov_sinai`（宝物槽 -1）、`cov_living_water`（满血治疗转 140px 冲击波，已在 `heal_player` 生效）、
  `cov_sun_stand`（完美闪避与升级冻结 2.2s，已生效）、`cov_reflect`（受伤反伤 35×伤害+10×护甲，已生效）、
  `cov_broken_jar`（破罐全屏致盲+战兢 3s、冷却 ×0.65 6s，已在 rewards 生效）、
  `cov_better_promise`（成全门槛 ×0.6）、`cov_david_throne`（每缺 1 把武器范围 +25%/伤害 +35%）、
  `cov_seven_spirits`（按异常种类加伤）、`cov_alpha_omega`（折返弹幕）留给战斗侧消费。
- 其余 8 张（星辰、天梯、盐、磐石、四活物、新心、万事、初终）目前只做数值近似，见 §8。

## 5. 奖励与掉落（src/systems/rewards.gd）

- **经验宝石四档**：`gem_tier(val)` → ≥100 星辰王冠石 `#BFD4FF`、≥25 绯红圣晶 `#F07A9A`、≥4 金黄 `#F0D890`、否则青绿 `#7FE0C0`。
- **合体防卡顿**：场上未拾取宝石 > 120 颗时，把离玩家最远的 20 颗（val<100）合成 1 颗（价值求和，clamp 9999）。
- **三档宝箱**：铜（1 级 + 25 银 + 回 15%）/ 银（3 级 + 60 银 + 回 30%）/ 金（5 级 + 必得军装 + 150 银 + 回 30%）；`chest_double` 时银两 ×2。精英掉落：<480s 铜、≥480s 银；`meteor_horde` 精英必金。
- **陶罐奇物**：场上维持 8 个，20s 补刷，靠近 22px 打破；权重按圣典 11.3：
  无花果饼 30% / 吗哪 20% / 以利沙盐 10% / 基甸瓦罐 12% / 银号角 8% / 寡妇油瓶 6% / 大卫囊袋 6% / 替罪羊角 5% / 火炭 3% / 钱袋（余量）。
- **祷告祭圈**：300s / 570s 各一处，站满 10s → 1 火炭 + 1 铜宝箱。

- 对外：`rewards.draw_data()` 返回 circle / chest / pot / pickup / ark；`add_gem`、`spawn_chest`、`on_elite_killed`、`silver_run`、`meta_silver_bonus`。

## 6. 成就钩子

- `RunAchievements.evaluate(victory, commit)` 在结算调用；条件判定读 `mechanics.flags` + `run.ach_flags`。
- 已实现 10 种 `cond.type`：`stage_clear / stage_clear_seal / kills_in_run / kills_total / no_damage / elite_kills / fusion_count / level_reach / survive_time / weapon_only`。
- `commit = (not sim_mode or save_run) and not no_meta` 时调用 `Meta.grant_achievement`。
- 章节内 flag 别名（与 achievements.json 对齐）：`no_forbidden_fruit / deep_water_stand_60s / friendly_fire_kill / water_wall_kill / lightning_kill / jericho_inner_wall / trample_kill / smash_all_bread / furnace_inner_zone / max_burn_kill / lamps_7 / armor_treasure_3 / perfect_dodge_5 / no_dodge`。

## 7. BOSS 接线与 21 阶

- BOSS 数据已迁到 `data/bosses.json`，run 侧在 `_altars_and_events` 生成后调用：
  `_recompute_boss()` → `mechanics.on_boss_spawn()` → `_ensure_boss_ai()`。
- `_ensure_boss_ai()` 优先接管 `EnemySim.boss_ai`（enemy_sim 在 spawn 时已挂 `BossAI` 并每帧 tick），只给它补 `ProjectileSim`；文件不存在时静默跳过，`_tick_boss_ai` 有 null 保护。
- `seal` 从 1–7 放宽到 **1–21**（`--seal=` 与 `Meta.effective_tier()` 都 clamp 1..21）；
  刷怪/血量/伤害走 `Meta.tier_enemy_hp/dmg/spawn_rate(seal)`，银两走 `Meta.seal_mult(seal)` + `stage_coin`。

## 8. 与圣典的差异（已知，不崩且可玩）

1. `lightning_zones`：圣典「敌我同伤 85」。自动驾驶躲不掉圈，85 点两发必死，所以玩家侧收 40%（34 点），敌人仍是 85。手操仍可躲。
2. `wall_ring`：只做了「绕跑 7 圈」，音波轰 50 次震塌未做（音波计数需武器侧回调，见 docs/V2-接口需求-systems.md）。
3. `pentecost_rush`：「弹幕附带圣火+致盲」需要 weapon_runner 读 `state` meta；当前用拾取瞬间 160px 范围上状态代替，冷却 -40% 已生效。
4. `glass_sea`：玻璃海的「导电/蒸汽」用「带灼烧或活水 → 连锁爆炸」近似；圣所光柱每 90s 只生成 1 个（一次性回满）。
5. `drought_fire`：倒水坛用「站满 4s（sim 3s）」代替「注满 4 桶水」的逐桶演出。
6. 约：`cov_alpha_omega / cov_david_throne / cov_seven_spirits / cov_better_promise / cov_sinai` 只写 meta，
   消费方（武器冷却与弹幕折返、宝物槽、成全门槛）在战斗/UI 侧，尚未全部接线。
7. `eden_fall`：荆棘只做移速 ×0.7（圣典 -30% 与经验 -15% 已由吃果惩罚覆盖）。
8. `belly_shade` / `darkness_lamp` 的视野用 `run.vision_radius` 输出，渲染侧裁剪由 UI 代理接线。
