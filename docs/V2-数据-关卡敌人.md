## 6. BOSS 三阶段与技能参数

三阶段的 at_hp 严格是 1.0 / 0.66 / 0.33（开场 / 约剩 2/3 / 约剩 1/3），每位至少 2 个技能；技能 id 只取契约第 9 节的 8 种，24 位共 148 个技能槽。

| 技能 id | params 键位 | 语义 |
|---|---|---|
| `ring_burst` | count, damage, speed | 以自身为圆心环形发射 count 发子弹，speed px/s |
| `aimed_shot` | count, damage, speed | 瞄准玩家扇形/连发，count 发 |
| `charge` | damage, speed, count | 红线预警后直线冲撞，count 次连冲 |
| `nova` | radius, damage | 自身周围 radius px 内一次爆发伤害 |
| `zone_denial` | radius, damage, duration, tick, count | 预警圈落下持续伤害，tick 秒一跳，同时 count 个 |
| `summon` | enemy, n | 召唤 n 只 enemy（必须是 enemies.json 里的 id） |
| `spawn_totem` | hp, count, duration | 布置可拆的柱/图腾，count 个、hp 血量、duration 秒 |
| `heal_self` | pct | 回复最大 HP 的 pct 比例 |

阶段设计：P1 两招（一个弹幕 + 一个近身/领域）→ P2 加入召唤或领域，把场地切开 → P3 冷却整体缩短 20%~40%，同时保留 P1/P2 的招（例如兽王终章 3-4 招同场）。终章 beast_of_sea 是特例（3/4/3 槽），其余 23 位统一 2/2/2。歌利亚 P2 用两条 summon（乌鸦×4 + 军兵×4）复刻圣典的「召护卫」；米甸双王带 twin:true / hp_split:2 扩展键，供双王实现使用。

## 9. 兼容与风险

- **elah_valley / judea_wilderness 原样**：id、章号 13/17、duration 780/690 与 750/660、budget 210/76/620 与 230/70/560、judea 的 enemy_speed=1.12 / shillings=1.25 / ground.rocks=true、elah 首段 soldier70+raven30 全部保留，校验脚本逐条断言。
- **BOSS 迁出 enemies.json**：goliath / the_tempter 从 enemies.json 删除，24 位 BOSS 全部进 bosses.json，并带 behavior:"boss" / tier:"boss" 便于装载器合并。**代价**：src/run.gd:738 仍从 enemies 表找 BOSS，现在会静默返回 -1 → 24 章全部没有关底 BOSS。这是本轮最高优先级的接口需求（见接口需求第 1 条）。
- **旧 phases 结构变了**：存量 goliath 写的是 "phases": [0.7, 0.35]（float 数组），契约 §9 是对象数组 [{at_hp, skills}]。grep 确认 src 里没有读 phases 的代码，所以现在无影响；boss_ai 接入时按契约写。
- **敌人类型表变长**：36 条进 GameData.enemies，run.gd:163-165 按表长构造类型；取类型一律走 type_index_of(id)（run.gd:708/730/738），没有硬编码下标，安全。
- **unlock_wins = 章号-1**：老存档 wins 不足时第 4 章以后会锁住，elah_valley 从"第 2 章的下一关"变成"需要 12 胜的第 13 章"。需要存档迁移或放宽曲线（见接口需求第 6 条）。
- **BOSS HP 与圣典绝对值**：圣典第 10 章的 BOSS HP 区间约 5200~12000，本轮按任务给定的 4000→40000 单调阶梯铺开（前 12 章约在 4000~8800，后 12 章 9500~40000）。若平衡轮决定回到圣典绝对值，只需改 bosses.json 的 hp 一列，其余字段不受影响。

## 10. 遗留问题

1. 24 个 mechanic_id 只是数据，行为（水位、雷击、视野、火窑……）全部待 sim 实现；目前玩家感受不到章节差异。
2. 关底 BOSS 生成、三阶段切换、zone_denial/spawn_totem/heal_self 三种技能需要 combat/systems 落地（接口需求 1、2）。
3. mods 20+ 个扩展键未接线（接口需求 5），其中 area/pierce_bonus 这类会直接影响手感。
4. 精英 12 种在第 1~5 章只轮换 2 种（拿非利巨灵 / 筑塔督工），第 6~8 章才加术士与铁车；如果希望前 8 章更有变化，可以从第 5 章起提前投放 3~4 种。
5. 本轮没有跑 --sim（sim 依赖的 src 文件正由其他人在改，且门禁在主控手上）；数据层验证止于 GameData 装载 + 自洽脚本。主控跑 gate 时建议带 --stage=elah_valley 与 --stage=ch01_eden 各一次，重点看关底 BOSS 是否出现。
