## 2. 基础库（已由主控写好，不要再改）

`src/render/sprite_bank.gd`（`class_name SpriteBank`）：
- `witnesses()/enemies()/props()/weapon_icons()/passive_icons() -> Texture2D`（缺失返回 null，内部缓存）
- `witness_row(id) -> int`、`enemy_row(id) -> int`（未知返回 -1）
- `frame_rect(row, frame) -> Rect2`、`prop_rect(kind, tier)`、`weapon_icon_rect(i)`、`passive_icon_rect(i)`
- `frame_index(time, speed_ratio) -> int`（0..3）

`src/ui/ui_theme.gd`（`class_name UITheme`）：`panel/scroll/metal_bar/icon_frame/etched_title/divider/button/star/rivet/text`，配色常量 `INK/INK_DEEP/INK_SOFT/GOLD/GOLD_BRIGHT/GOLD_PALE/PARCH/PARCH_DIM/BLOOD/OLIVE`。

## 3. 跨文件契约（各代理必须严格实现/使用）

### 3.1 `src/run.gd`（owner: run-systems）对外暴露
```gdscript
var paused: bool = false            # 暂停中
var pause_index: int = 0            # 0 继续试炼 / 1 重开本局 / 2 返回营地 / 3 音效静音
var muted: bool = false             # 音效静音（写进 sfx）
var picked_shillings: int = 0       # 本局已拾取舍客勒
var dmg_events: Array = []          # 浮动伤害：{x: float, y: float, amt: float, crit: bool}，最多保留 200 条
var ground_coins: Array = []        # 地面银币：{x: float, y: float, v: int, t: float}，由 run 生成/拾取，渲染层只读
func toggle_pause() -> void         # 仅在 not over and not modal 时生效
func pause_confirm() -> void        # 执行 pause_index 对应动作
func pause_move(dir: int) -> void   # 上下移动选中项
```
暂停时 `step()` 不推进世界；重开 = `get_tree().reload_current_scene()`；返营地 = `change_scene_to_file.call_deferred("res://scenes/camp.tscn")`。

### 3.2 `src/combat/weapon_runner.gd`（owner: combat-mods）
```gdscript
var on_damage: Callable = Callable()   # 每次对敌人造成伤害后调用 on_damage.call(x, y, amount, crit)
```
`run` 在 `_ready` 里把它接到 `dmg_events.append(...)`（封顶 200）。

### 3.3 `src/sim/enemy_sim.gd`（owner: run-systems，仅新增，不改既有字段语义）
```gdscript
var flash: PackedFloat32Array   # 与 hp 等长；受击置 0.12，update 里衰减到 0；swap_remove 时同步迁移
var sim_time: float = 0.0       # 累计时间（替换 Time.get_ticks_msec 的一切用法）
```

## 5. 验证口径

- 代理**不要执行** `--import`、`--sim`、`--shot*`（并发 import 会互相踩缓存，截图由主控统一跑）。
- 允许的本地检查：`HOME=$PWD/.godot_home /Applications/Godot.app/Contents/MacOS/Godot --headless --path . --check-only --script res://<你的文件>`，日志里不能出现 `SCRIPT ERROR`。
- 主控统一跑五条门禁：`--import`、`--sim --sim-speed=900 --no-meta`、`--camp-selftest`、`--shot`（窗口，一次）、`--shot-title/--shot-camp`。

## 6. 美术口径

- 分辨率基准 640×360，整数缩放；纹理 filter 已是 nearest。
- 禁止模糊拉伸：图集只用 `draw_texture_rect_region`（或 `draw_texture_rect`）按 1:1 或整数倍绘制。
- 受击闪白：`modulate` 通道乘到 `Color(2.0, 2.0, 2.0, 1.0)` 会过曝，按 `flash * 6.0` 夹到 1.6 上限。
