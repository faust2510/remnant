## 播放器对外接口（`src/core/sfx.gd`）

```gdscript
func play(id: String, vol_db: float = 0.0, pitch: float = 1.0, cd: float = 0.035) -> void
var enabled: bool = true                     # 旧契约：false 时一切静音（run.gd 暂停菜单在写它）
func has_sound(id: String) -> bool
func sound_names() -> Array

# 垫乐
func play_music(path := "res://assets/music/camp_loop.ogg", vol_db := 0.0, fade_s := 1.2) -> void
func stop_music(fade_s: float = 0.6) -> void
func is_music_playing() -> bool

# 总线开关（互不干扰）
func set_sfx_enabled(v: bool) -> void
func set_music_enabled(v: bool) -> void
func is_sfx_enabled() -> bool
func is_music_enabled() -> bool
func set_bus_volumes(sfx_db: float, music_db: float) -> void
```

- `play()` 未知音名**静默忽略**：不打印、不 push_error、不阻塞。
- 音量/pitch 都做钳制（volume -60..+6 dB，pitch 0.5..2.0），不会因为调用方传怪值炸响。
- 每文件有基础冷却（`FILE_SPEC`），调用方传更长的 `cd` 时取更长一侧；Boss/升级/死亡 0.2–0.8 s，避免密集触发叠成噪声。
- 16 路播放器轮转（`POOL = 16`），流有进程级 `static` 缓存，四个界面各 new 一个 `Sfx` 也不会重复解码。
- 垫乐用 `static _music_owner` 保证同一时刻只有一路在放，场景切换不会叠两层。

## 混音

```
Master  ←  SFX   (-2.0 dB)
        ←  Music (-8.0 dB)
```

- 项目里没有 `default_bus_layout.tres`、`project.godot` 也没有 `[audio]` 段，所以两条总线在 `_ready()` 里由 `_ensure_buses()` 运行时创建（幂等：已存在则只改电平）。没有新增 `.tres`，避免越界写别的 agent 的目录。
- `set_sfx_enabled(false)` 只静音 SFX 总线；`set_music_enabled(false)` 静音 Music 总线并停掉垫乐。两者互不影响，也不影响 `enabled`。
- 音效文件本身已归一化到 -3 dBFS，叠加总线 -2 dB 后峰值约 -5 dBFS，给混音留了余量。

## 垫乐设计

| 项 | 取值 |
| --- | --- |
| 时长/调性 | 64.000 s / A 小调，60 BPM，4 s 一小节 × 16 小节 |
| 和声 | Am → F → C → G 循环，四声部根音在低音区，上方三音声部交叠 |
| 音色 | 管风琴（1–4 次泛音 + 5.2 Hz 浅 tremulant）、合唱 pad（A 元音共振峰 700/1090/2440 Hz）、pedal bass |
| 立体声 | 左右 ±5–6 音分 detune、不同相位 tremulant、合唱 vibrato 反相，混响 IR 用两个种子 → 宽度来自失谐而不是延迟 |
| 结构 | 前 2 小节只留 pedal 慢浮上来；3–11 小节满编制；12–15 小节抽掉合唱层收气；4/6/8/10/12/14 小节各落一个长音（880/1318.5/1046.5/880/1318.5/987.77 Hz）当呼吸点 |
| 无缝循环 | 所有音符用 `_add_wrap()` 环形叠加（越过末尾的尾巴绕回开头）；混响用 `_reverb_circular()` 环形 FFT 卷积，残响同样绕回开头，接缝处没有断掉的混响 |
| 编码 | ffmpeg Vorbis。本机 ffmpeg 8.1 **没有 libvorbis**，脚本先试 `-c:a libvorbis`，失败退 `-c:a vorbis -strict -2 -qscale:a 8`（Godot 自带的原生 vorbis 解码器可读），再失败才落 wav |
| 循环点 | 导入参数 `loop=true`，运行时 `_prepare_loop()` 对 Ogg 再设一次 `loop=true / loop_offset=0`（wav 兜底时把 `loop_end` 推到末尾） |

循环实测：`camp_loop.ogg` 解码后 2,822,400 帧 = 64.000 s × 44100 × ... 与源 wav 逐样本对齐（连续两轮解码总帧数完全等于源，不会一轮比一轮漂移）；首尾接缝跳变 1123.0，而相邻样点跳变的 99 分位是 703.0 → 接缝不突兀。

## 无头降级（硬门禁）

`_detect_audio()` 两个判据：`DisplayServer.get_name() == "headless"` 或 `AudioServer.get_driver_name()` 为空/`Dummy`。
命中则 `_ready()` 立刻 `set_process(false)` 并返回：不建总线、不建播放器、不 `load()` 任何流，`play()` / `play_music()` 直接 return。因此 `--headless` 下即使 `run.gd` 每帧调用 `sfx.play()` 也没有任何音频子系统参与。

## 已知限制

- 中间产物 `tools/out/camp_loop.wav`（11 MB，Vorbis 编码前的立体声母版，未跟踪、可随时删）由 `gen_sfx.py` 留在 `tools/out/`，方便以后换编码器重转；不需要时直接删，不影响游戏运行。
- 本机 ffmpeg 无 `libvorbis`，用的是 ffmpeg 原生 `vorbis` 编码器（`-strict -2`）。Godot 解码正常，但编码器可能有轻微相位噪声；想要更保险可以换 `libopus`（Godot 4.7 支持 `.ogg`+opus 容器）或装带 libvorbis 的 ffmpeg 后重跑。
- 只有一首垫乐（营地/主循环共用）。战斗/Boss 层音乐没有做，后续可以复用同一套环形合成流程加 `battle_loop.ogg`，`play_music(path)` 已支持传路径。
- 音效未做 music ducking（升级/受伤时压低音乐）——需要的话用 `AudioServer` 的 bus effect 或 `set_bus_volumes` 手写 tween。
- `.wav` 已改 PCM，仓库里 12 个文件共约 360 KB；如果以后要压包体大小，可以单独把长音（level_up/fuse/boss/defeat）改回 QOA，短瞬态保持 PCM。

## 二次修改流程

1. 只改 `tools/gen_sfx.py`（`SFX_TABLE` 加法，或改 `s_xxx()` 的合成参数）；
2. `python3 tools/gen_sfx.py`（会 prune 表外文件，幂等）；
3. 若改了文件名，同步更新 `src/core/sfx.gd` 的 `FILE_SPEC` 和 `ALIASES`；
4. 跑 `--import` + `--sim` 两条门禁。

> 注意：`gen_sfx.py` 使用固定种子；想换"另一个版本"的同一音效，改种子或改参数，不要靠 `np.random` 的全局状态。
