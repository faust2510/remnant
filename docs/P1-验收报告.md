## 三、本轮修掉的问题

1. `chooser.close()` 只在祭坛分支调用，领受面板关闭后仍残留 → 画面被面板盖住（截图里最明显）。
2. `_save_shot` 里 `await RenderingServer.frame_post_draw` 期间游戏继续跑，截到的是下一帧 → 改成先冻结 3 帧再取图。
3. 敌人接触伤害按「接触个数求和」结算，被 3 只围住一帧掉 16 点 → 改成只吃最强的一下。
4. `lifesteal`（仁爱果子）只写进了 stats，从未参与结算 → 击杀回血现在真的生效。
5. 生成的敌人落在圆形环上（215–280px），在 640×360 里会直接出现在屏幕内 → 改成在可视矩形外沿生成。
6. 敌人速度 50 追不上玩家 72，屏幕上永远只有背影 → 全体提速到 52–66，乌鸦 100。
7. 摄像机 1:1 → 1.35，角色与敌人不再像蚂蚁。
8. 升级时 `player_hp` 只做了一次 min 运算（等于没回血）→ 现在每次领受回复 12% 上限。
